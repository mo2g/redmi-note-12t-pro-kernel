# Security Policy

This repository is a defensive kernel-patching toolkit. Please:

- Do **not** paste device serial numbers, IMEI/MEID, phone numbers, account
  information, personal logs, hidden Magisk package names, or full partition
  backups into issues or pull requests.
- Do **not** publish exploit code or PoCs for unpatched devices. CVE-2026-43499
  is already public; keep discussions focused on detection, patching, and
  verification.
- For build or flashing problems, include the kernel version, ROM build,
  patch list, toolchain version, `check_kernel.sh` output, and relevant kernel
  logs with personal data removed.
